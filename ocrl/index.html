OCRL Project: LQR-Based Balance Control for a Bipedal Wheel Robot

Designed and simulated an LQR + Virtual Model Control (VMC) framework to stabilize a planar bipedal wheeled robot with a five-bar leg mechanism, enabling upright posture regulation and coordinated wheel/leg torque allocation.

🧭 Project Overview

Bipedal wheeled robots combine leg agility with wheel efficiency, but maintaining balance is difficult due to nonlinear, underactuated dynamics and configuration-dependent behavior. This project develops a full-state LQR controller for body posture regulation and augments it with Virtual Model Control (VMC) to convert task-space objectives into joint torques.

Planar model reduction Upright equilibrium linearization Offline Riccati solve Online gain interpolation Jacobian-transpose torque mapping

🧠 Methods

Dynamic Modeling

To make the control problem tractable, the five-bar leg structure is reduced to a planar model (wheel + rigid leg + rigid body). Using Newton–Euler equations, the coupled dynamics are derived and rewritten in first-order state-space form.

  • State vector x includes positions/angles and their velocities.
  • Input vector u contains wheel torque and hip torque.
  • The model is linearized about the upright equilibrium.

LQR Design with Gain Scheduling

An LQR controller is designed on the linearized system to minimize a quadratic cost on state deviation and control effort, using u = -Kx from the continuous-time algebraic Riccati equation. Since effective leg length changes during motion, gains are scheduled versus leg geometry:

  • Compute LQR gains offline for discrete leg lengths.
  • Fit cubic polynomials to each gain entry vs. leg length.
  • Interpolate K(L₀) online using the current leg geometry.

Virtual Model Control (VMC)

VMC maps task-space virtual forces (spring–damper behavior) into joint torques using T = JᵀF, where F encodes desired support and damping and J is the task Jacobian.

Closed-loop architecture: state feedback for body regulation (LQR) + task-space to joint-space mapping (VMC).

🧪 Experimental Setup

The controller is evaluated in MATLAB simulation using a planar five-bar leg + wheel model. The closed-loop pipeline includes state estimation, upright posture reference tracking, online gain scheduling, and torque command generation for wheel and leg actuators.

  • Full-state feedback using simulated measurements of angles/positions and velocities.
  • Reference forward velocity and near-upright body pitch target.
  • Online evaluation of K(L₀) from the scheduled gain model.
  • Torque allocation via VMC for leg tasks and wheel propulsion.

📈 Results

Simulation results indicate the controller maintains upright balance and coordinates wheel/leg torques during cyclic motions. The body pitch remains near zero while legs swing, and torque commands remain smooth without abrupt spikes.

  • Posture regulation: body pitch stays close to upright during motion.
  • Torque coordination: smooth wheel and hip torques with higher demand during transitions.
  • Tracking behavior: leg speed tracking aligns with commanded profiles in simulation.
  • Motion validity: animations confirm stable gait execution without loss of balance.

💬 Discussion

Combining LQR (for body regulation) with VMC (for torque mapping) provides a clean, modular controller structure. Gain scheduling adapts the feedback law to changing leg geometry while avoiding online Riccati solves, keeping runtime computation lightweight.

Current performance is demonstrated in an idealized simulation. Hardware deployment would require addressing parameter uncertainty, sensing noise, and ground interaction variability (e.g., friction changes). Future work could add robustness analysis and/or learning-based adaptation to refine gains online.
