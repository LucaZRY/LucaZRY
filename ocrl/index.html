OCRL Project: LQR-Based Balance Control for a Bipedal Wheel Robot

Course project for Optimal Control & Reinforcement Learning (OCRL): designing and simulating an LQR + Virtual Model Control framework for a bipedal wheel robot with a five-bar leg mechanism.

Introduction

Bipedal wheeled robots combine the agility of legged locomotion with the efficiency of wheels, making them attractive for navigating cluttered indoor spaces and uneven terrain. However, balancing such systems is challenging because of their nonlinear, underactuated dynamics and changing ground contact conditions.

This project develops a Linear Quadratic Regulator (LQR)–based balance controller, combined with Virtual Model Control (VMC), for a simplified bipedal wheel robot model. The goal is to stabilize the robot’s body posture, coordinate leg and wheel torques, and track desired motions in simulation, building a foundation for future hardware deployment.

Methods

Dynamic Modeling

To make the control problem tractable, the full five-bar leg structure is first reduced to a planar model consisting of a wheel, a rigid leg, and a rigid body. The configuration is described by wheel translation, leg pitch angle, and body pitch angle, actuated by a wheel motor torque and a hip torque. Using Newton–Euler equations, the coupled dynamics are derived and then rewritten in first-order state-space form:

  • State vector x includes joint angles, positions, and their velocities.
  • Input vector u contains the wheel and hip torques.
  • The system is linearized about the upright equilibrium.

LQR Design with Gain Scheduling

On the linearized model, an LQR controller is designed to minimize a quadratic cost on state deviation and control effort. The controller uses full-state feedback u = -K x, where the gain matrix K is obtained by solving the continuous-time algebraic Riccati equation.

Because the robot’s effective leg length changes during motion, the dynamics – and thus the optimal gains – vary with configuration. To handle this, gain scheduling is used:

  • Compute LQR gains offline for discrete leg lengths.
  • Fit cubic polynomials to each gain entry as a function of leg length.
  • Interpolate K(L₀) online based on the current leg geometry.

Virtual Model Control (VMC)

For the planar five-bar leg, Virtual Model Control is used to map task-space virtual forces into joint torques. A virtual spring–damper in task space generates desired vertical support force and leg orientation; these forces are projected into joint space using the Jacobian transpose:

  • Task variables: leg length L₀ and leg orientation.
  • Virtual force vector F encodes desired behavior (e.g., support, damping).
  • Joint torques are computed as T = Jᵀ F.

The final closed-loop controller combines LQR body regulation with VMC-based torque allocation in the leg joints.

Experimental Setup

The controller is evaluated in MATLAB simulation using a planar five-bar leg + wheel model. The closed-loop architecture includes:

  • State estimation of body and leg angles, positions, and velocities.
  • A reference forward velocity and upright body posture.
  • Online gain scheduling based on current leg length.
  • Torque commands to wheel and leg actuators computed from LQR + VMC.

Results

Simulation studies show that the controller can maintain upright balance and coordinate wheel and leg motion over cyclic reference trajectories. Key observations include:

  • Body elevation angle: the body pitch remains close to zero while the legs swing, indicating successful posture regulation.
  • Torque coordination: wheel and leg torques exhibit smooth, alternating patterns, with higher demands during transition phases but no abrupt spikes.
  • Motor speed tracking: commanded and measured leg speeds overlap closely, demonstrating strong velocity tracking.
  • Trajectory execution: visualizations of the robot’s motion confirm that the robot follows the intended gait while staying balanced.

Discussion

The combination of LQR and VMC provides a principled way to stabilize a bipedal wheel robot around an upright configuration while coordinating multiple actuators. The gain scheduling scheme allows the controller to adapt to changing leg geometry without solving a Riccati equation online, which keeps the implementation lightweight.

The current results are obtained in an idealized simulation with accurate models and noise-free sensing. Real hardware introduces parameter uncertainty, sensor noise, and ground friction variations, which may degrade performance. Future work will extend the framework with robustness analysis and potentially learning-based adaptation to tune the gains online.
