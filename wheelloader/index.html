📌 Project Overview

This project investigates how reinforcement learning and trajectory optimization can be used to generate efficient bucket motions for an articulated wheel loader. The goal is to automate repeated scooping tasks in a construction setting while respecting realistic constraints on forces, geometry, and interaction with granular material.

A custom environment was built in Isaac Sim / IsaacLab with articulated arm and bucket dynamics, contact-rich interaction with a rock pile, and task-specific rewards that capture bucket fill-level, energy usage, and motion smoothness.

Task: Scooping & loading rocks Observation: joint states + bucket pose Action: continuous joint torques / velocity cmds Algorithm: PPO / custom RL pipeline

🛠️ Technical Details

Simulation & Dynamics

  • Articulated wheel-loader model with arm and bucket joints, PD-based torque control, and configurable joint limits.
  • Rock pile modeled using multiple rigid bodies / particles with tuned contact parameters and friction coefficients.
  • Bézier curve–based nominal scooping trajectories used as initial policies and for debugging motion profiles.

Reinforcement Learning Setup

  • State space includes joint positions, velocities, bucket pose, and limited environment features (e.g., pile height).
  • Action space is continuous: joint torques or joint velocity targets for arm and bucket joints.
  • Reward combines bucket fill level, energy / torque penalties, smoothness of motion, and collision / limit violations.
  • Trained using PPO-style algorithms (e.g., via Stable Baselines3) with curriculum over pile configurations.

Wheel-Loader Reinforcement Learning Project

This project focuses on learning autonomous scooping motions for a wheel loader using reinforcement learning within a high-fidelity Isaac Sim environment.

Introduction

Construction sites frequently rely on wheel loaders to handle repetitive scooping and loading tasks. These tasks require precision, physical endurance, and operator experience, often leading to fatigue and inconsistent performance. To address this real-world inefficiency, this project investigates whether reinforcement learning can generate smooth, reliable, and efficient scooping motions for autonomous wheel-loader operation.

The objective of this project is to develop and evaluate a reinforcement-learning policy capable of performing bucket scooping in simulated granular media using Isaac Sim / IsaacLab.

Methods

A custom Isaac Sim / IsaacLab environment was built to model the articulated arm and bucket of a wheel loader. The system observes joint positions, velocities, bucket pose, and contact information, and outputs continuous torque or velocity commands to control the scooping motion.

The simulation includes:

  • Realistic granular rock piles
  • Custom USD environment assets (walls, boundaries)
  • Accurate joint/actuator limits
  • PD-based torque controllers

A Bézier-curve-based trajectory was used as the initial scripted baseline. A PPO-style reinforcement learning agent improved this baseline using a reward function designed to encourage deeper penetration, smooth torques, efficient motion, and higher bucket fill levels.

Results

The trained RL policy produced smoother and more consistent scooping behaviors than the scripted baseline. It achieved higher average fill levels and reduced torque spikes, demonstrating better control of the bucket’s penetration angle and trajectory curvature during the scooping phase.

Key results include:

  • Higher bucket fill levels across randomized piles
  • Reduced torque spikes and smoother actuator profiles
  • More reliable scooping angle selection
  • Improved consistency over scripted baseline motions

Discussion

These results suggest that reinforcement learning can significantly improve material-handling efficiency in construction automation. Although the simulation still simplifies certain physical effects, the RL policy demonstrated encouraging robustness to variations in pile shape and rock distribution.

Future work includes domain randomization for sim-to-real transfer, integration with perception modules for environment-aware scooping, and deployment on real-world robotic loader hardware.
